    Capítulo 4. Instalación y despliegue de Apache NiFi 2.x con Docker

    Objetivo del capítulo: desplegar Apache NiFi 2.x utilizando Docker Compose y comprender la estructura básica de una instalación lista para desarrollo.

    Objetivos de aprendizaje

    Al finalizar este capítulo serás capaz de:

    • Comprender las ventajas de ejecutar NiFi mediante contenedores.
    • Desplegar Apache NiFi utilizando Docker Compose.
    • Identificar los directorios persistentes.
    • Acceder a la interfaz web.
    • Verificar el correcto funcionamiento de la instalación.
    • Resolver los problemas más habituales.

    4.1 ¿Por qué utilizar Docker?

    Docker permite ejecutar Apache NiFi de forma aislada, reproducible y sencilla.

    Ventajas

    • Instalación rápida.
    • Sin dependencias locales.
    • Fácil actualización.
    • Entornos reproducibles.
    • Eliminación sencilla.

    Buena práctica

    Utiliza Docker durante el desarrollo y aprendizaje. Para producción pueden emplearse Docker, Kubernetes o despliegues tradicionales.

    4.2 Requisitos

    • Docker Engine 24 o superior.
    • Docker Compose v2.
    • 4 GB de memoria RAM (mínimo recomendado).
    • Puerto TCP 8443 disponible.

    Comprueba la instalación:

    docker --version
docker compose version

    4.3 Estructura del proyecto

    nifi-lab/
├── docker-compose.yml
├── conf/
├── state/
├── content_repository/
├── flowfile_repository/
├── provenance_repository/
└── logs/

    Cada directorio almacenará información persistente del contenedor.

    4.4 Docker Compose

    Crea el archivo docker-compose.yml.

    services:
  nifi:
    image: apache/nifi:2.10.0
    container_name: nifi
    restart: unless-stopped

    ports:
      - "8443:8443"

    environment:
      SINGLE_USER_CREDENTIALS_USERNAME: admin
      SINGLE_USER_CREDENTIALS_PASSWORD: "changeme"
      NIFI_WEB_HTTPS_HOST: "0.0.0.0"
      NIFI_WEB_HTTPS_PORT: "8443"
      NIFI_WEB_PROXY_HOST: "0.0.0.0:8443,localhost:8443,nifi:8443"


    volumes:
      - nifi_conf:./nifi-current/conf
      - nifi_logs:./nifi-current/logs
      - nifi_flowfile_repository:./nifi-current/flowfile_repository
      - nifi_content_repository:./nifi-current/content_repository
      - nifi_provenance_repository:./nifi-current/provenance_repository
      - nifi_state:./nifi-current/state
      - ./datos:/datos

volumes:
  nifi_conf:
  nifi_logs:
  nifi_flowfile_repository:
  nifi_content_repository:
  nifi_provenance_repository:
  nifi_state:

    Contraseña

    Cambia la contraseña por una más segura antes de utilizar este entorno fuera de un laboratorio.

    4.5 Puesta en marcha

    Inicia el servicio:

    docker compose up -d

    Comprobar el estado:

    docker compose ps

    Visualizar el registro:

    docker compose logs -f nifi

    Detener el entorno:

    docker compose down

    4.6 Primer acceso

    Abre el navegador:

    https://localhost:8443/nifi

    Inicia sesión con las credenciales configuradas.

    Figura 4.1: Pantalla de inicio de sesión de Apache NiFi 2.10 (pendiente de insertar).

    4.7 Directorios persistentes

    Directorio Finalidad

    conf Configuración logs Registros flowfile_repository Estado de FlowFiles content_repository Contenido provenance_repository Historial state Estado interno de componentes

    4.8 Verificación

    Comprueba:

    • La interfaz carga correctamente.
    • Es posible iniciar sesión.
    • El Canvas aparece vacío.
    • No existen errores críticos en los logs.

    4.9 Problemas habituales

    El puerto está ocupado

    lsof -i :8443

    El contenedor no inicia

    docker compose logs nifi

    No puedo acceder desde el navegador

    • Comprueba el puerto publicado.
    • Verifica que Docker esté en ejecución.
    • Revisa el firewall.

    Note

    Durante el primer arranque NiFi puede tardar varios minutos en estar disponible.

    4.10 Buenas prácticas

    • Utiliza siempre volúmenes persistentes.
    • Versiona únicamente los archivos de configuración.
    • No almacenes contraseñas reales en el repositorio.
    • Mantén actualizado el contenedor.
    • Documenta cualquier cambio de configuración.

    Laboratorio guiado

    1. Crear la estructura del proyecto.
    2. Crear el archivo docker-compose.yml.
    3. Iniciar NiFi.
    4. Acceder a la interfaz web.
    5. Verificar los logs.
    6. Detener el contenedor.
    7. Reiniciarlo comprobando que la configuración se mantiene.

    Resumen

    En este capítulo has aprendido a desplegar Apache NiFi 2.x mediante Docker Compose, identificar sus directorios principales y verificar que la instalación funciona correctamente. Este entorno será la base para construir los primeros flujos de datos en el siguiente capítulo.
