    Introducción a Apache NiFi 2.x

    ¿Qué es Apache NiFi?

    Apache NiFi es una plataforma de código abierto destinada a automatizar el movimiento, tratamiento y distribución de datos entre diferentes sistemas.

    Permite diseñar flujos de datos mediante una interfaz gráfica accesible desde el navegador. En ella se incorporan y conectan distintos componentes para obtener datos, transformarlos, dirigirlos hacia diferentes destinos y supervisar todo el proceso.

    Apache NiFi puede recibir información procedente de múltiples fuentes, como:

    • archivos locales;
    • APIs REST;
    • bases de datos;
    • sistemas de mensajería;
    • dispositivos IoT;
    • servicios en la nube;
    • Apache Kafka;
    • servidores FTP o SFTP.

    Posteriormente, puede validar, filtrar, transformar, dividir, combinar, enriquecer o enrutar esos datos y enviarlos a otros sistemas.

    Un flujo sencillo podría ser:

    API REST → Apache NiFi → PostgreSQL

    Otro flujo más próximo a una arquitectura Big Data sería:

    API REST → Apache NiFi → Apache Kafka → Apache Spark

    ¿Qué problema resuelve?

    En una organización, los datos suelen encontrarse distribuidos entre aplicaciones, bases de datos, ficheros, sensores, plataformas cloud y servicios externos.

    Cada sistema puede utilizar formatos, protocolos, frecuencias de actualización, mecanismos de autenticación y estructuras de datos diferentes.

    Apache NiFi actúa como una capa de integración entre estos sistemas. Su función consiste en controlar cómo entran los datos, por dónde circulan, qué transformaciones reciben y a qué destino se envían.

    DataFlow

    En Apache NiFi se utiliza el concepto de DataFlow o flujo de datos.

    Un DataFlow describe el recorrido que realizan los datos desde su origen hasta su destino, incluyendo las operaciones que se aplican durante ese recorrido.

    Entrada → Procesamiento → Salida

    Ejemplo:

    Leer CSV → Convertir a JSON → Guardar en PostgreSQL

    ¿Es Apache NiFi una herramienta ETL?

    Apache NiFi puede realizar procesos ETL (Extract, Transform y Load), pero su principal especialidad es la automatización y gestión de flujos de datos.

    Resulta especialmente útil para:

    • ingestar datos;
    • conectar sistemas;
    • enrutar información;
    • cambiar formatos;
    • aplicar transformaciones ligeras;
    • controlar errores y reintentos;
    • supervisar el movimiento de los datos;
    • conservar su trazabilidad.

    Características principales

    • Interfaz gráfica basada en componentes.
    • Gran cantidad de procesadores para múltiples tecnologías.
    • Gestión de colas y back pressure.
    • Sistema de Data Provenance para la trazabilidad.
    • Seguridad mediante HTTPS, TLS y control de acceso.
    • Escalabilidad mediante clústeres.

    NiFi y Kafka

    NiFi se centra en la integración y automatización de flujos de datos, mientras que Kafka actúa como plataforma distribuida de mensajería y eventos.

    API → NiFi → Kafka → Procesamiento

    Casos de uso

    • Importación de archivos.
    • Consumo de APIs REST.
    • Integración con bases de datos.
    • Publicación y consumo de Kafka.
    • Conversión de formatos.
    • Integración con servicios cloud.
    • Pipelines de observabilidad y ciberseguridad.

    Objetivos de la unidad

    Al finalizar esta unidad, el alumnado será capaz de:

    1. Comprender el papel de Apache NiFi.
    2. Instalar y ejecutar NiFi.
    3. Diseñar flujos básicos.
    4. Comprender el funcionamiento de los FlowFiles.
    5. Integrar NiFi con diferentes sistemas.
